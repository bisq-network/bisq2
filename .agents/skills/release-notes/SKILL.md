## Release Notes

When release notes are requested:

* Create them in the project's `release-notes` directory.
* Follow the existing release-note structure, naming, tone, and conventions of the project.
* Unless project-specific instructions say otherwise, produce:

  1. full release notes,
  2. notable changes,
  3. release highlights.
* Base release notes on verified changes rather than assumptions from commit titles alone.
